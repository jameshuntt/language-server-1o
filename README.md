# language-server-1o

Standalone Rust 1o language server (LSP over stdio), CLI, schema-aware validation, and 1o AST export. Depends on `core-1o` from crates.io.

Published on [crates.io](https://crates.io/crates/language-server-1o).

```bash
cargo install language-server-1o
```

The existing VS Code extension is maintained separately at [1oLanguageSupport](https://github.com/jameshuntt/1oLanguageSupport).
